# Font sources

Unmodified Latin WOFF2 subsets returned by Google Fonts CSS2 requests (Instrument Sans on 2026-10-22, Instrument Serif on 2026-11-19). All files are self-hosted; no page requests a font CDN.

Instrument Serif (display) is weight 400 with separate normal and italic files. Instrument Sans (text and interface) provides weights 400, 500, and 600 in one variable file. Only the normal serif and the sans file are preloaded.

Both families use the SIL Open Font License 1.1. The original license texts are included alongside the fonts.
