# Font sources

Unmodified Latin WOFF2 subsets returned by the existing Google Fonts CSS2 request on 2026-10-22.

Instrument Sans provides weights 400, 500, and 600 in one variable file. Newsreader is weight 400, with separate normal and italic files. Only the normal faces used above the fold are preloaded.

Both families use the SIL Open Font License 1.1. The original license texts are included alongside the fonts.
